# Z-Anatomy 中文版 — Blender 5.0+ 适配与优化
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.186/Z-Anatomy-cn-Blender-5.webp)

[Z-Anatomy-cn-Blender-5](https://github.com/hendasheng/Z-Anatomy-cn-Blender-5) 是我基于开源人体解剖项目 [Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy) 和 [Dean Song 中文版](https://github.com/Dean-Song-1/z-anatomy-) 进行适配、修复与优化的版本，主要解决了旧版在 Blender 5.0+ 中的兼容性问题，同时完善了中文界面、词条搜索和操作体验。

性能方面最大的变化是所有文本都从网格文字改为 UI 绘制，保留显示功能的同时极大减少顶点和面数的开销。目前已在 Blender 5.2 中完成测试。

# 如何做自己的 Blender 插件
上面两个项目基本都是为了解决自己的需求而做的 Blender 插件。放在以前，开发插件是个学习成本很高的事情，一些简单但很个人的需求就难以实现。

现在看就不是这么回事了，目前 AI 工具的发展状况，足以支撑每个人都可以实现自己想要的功能，从需求梳理、功能实现到逐步完善功能，都已经不再困难。

这当然不意味着完全不需要理解代码，该有的难题依然存在，比如要解决什么问题，把问题描述清楚这件事目前依然很难；还有怎么解决问题，AI 会给你选择，如何完成选择需要一定的前置储备 ... 等等问题。

所以还是两头看，至少 AI 把开发门槛大大降低，可以从很小的需求出发，在实际的测试中尝试验证和实现需求，而不用经过漫长的学习之后才能开始自己的尝试。

# Loudroom / 大声练琴 — 练琴工具
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.186/%E5%A4%A7%E5%A3%B0%E7%BB%83%E7%90%B4.png)

[Loudroom / 大声练琴](https://github.com/hendasheng/dasheng-instrument) 是我正在开发的一个交互式音乐练习工具。最初是为了方便自己学习吉他和乐理，希望把音阶、音程、指板位置和实际声音结合起来，静态图表看起来很麻烦，希望交互式的表现能更直观一些。

目前的 0.1 版本主要围绕吉他音阶练习展开，支持 12 个调、9 种音阶，以及 CAGED 指板系统。可以在完整指板和 C、A、G、E、D 五种把位形状之间切换，观察同一个音阶在不同位置上的分布，更直观地理解音阶与实际演奏位置之间的关系。
