# Tango Flux × Botanica 
![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.171/tangoflux.png)

[TangoFlux](https://github.com/declare-lab/TangoFlux) 是由 DeCLaRe 实验室和 NVIDIA 合作推出的文本到音频生成模型（[在线体验](https://huggingface.co/spaces/declare-lab/TangoFlux)）。在 vol.156 中有详细的安装介绍。

再次推荐的原因跟 Botanica 有很大关系，这类音乐经常需要大量自然环境采样：风声、鸟叫、蝉鸣、雨声、溪流、树叶摩擦、木头碰撞声等等。这些声音采样在经过剪辑、叠加、降噪、拉伸、颗粒化、滤波和混响处理之后，就会变成音乐里非常重要的纹理。

我们很难接触到那么丰富的环境，来自己录制各种采样，TangoFlux 正好可以补充采样的丰富性，完全可以把它当成采样生成器来用。

# Radiance Fields - 高斯泼溅资讯与资源站
![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.171/Radiance%20Fields.png)

[Radiance Fields](https://radiancefields.com/) 是一个专注于 Radiance Fields、NeRF 和 3DGS（高斯泼溅） 的资讯与资源网站。

不是只讲概念，而是持续跟踪这个方向里的新工具、新论文、新平台和行业应用。首页就能看到最近的高斯泼溅新闻，还有各家软件、平台对高斯泼溅的支持进展。

# dd_GlitchAssist - Datamosh 数据损坏处理
![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.171/dd_GlitchAssist.png)

[dd_GlitchAssist](https://dazdisley.co.uk/dd_GlitchAssist/) 是 Daz Disley 做的一个 Windows 图形界面工具，本质上是 [FFglitch](https://ffglitch.org/) 的前端。FFglitch 本身基于 FFmpeg，可以对视频编码数据进行更底层的修改，而 dd_GlitchAssist 则把这些命令和脚本包装成了更容易使用的界面。

它适合用来做 Datamosh、压缩损坏、运动矢量错位、画面撕裂、块状崩坏等效果。
