这类基础课程的价值比大多数 “AI 屌爆”的宏大论述大的多，不忽悠你未来多夸张，而是告诉我们如何使用当下的工具。

# CLI × GUI - 命令行界面 / 图形用户界面
![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.172/cli-gui.png)

[图形用户界面（GUI）](https://www.wikiwand.com/en/Graphical_user_interface) 通过窗口、图标、菜单和按钮提供可视化操作。用户可以在界面中浏览功能，再通过单击、拖拽等方式完成任务。如今，大多数应用程序和软件系统都采用 GUI。

[命令行界面（CLI）](https://www.wikiwand.com/en/Command-line_interface) 则主要通过键盘输入文本命令，与操作系统或软件进行交互。它可以用来配置系统、操作文件、运行程序，也常用于服务器管理、远程环境和自动化任务。

GUI 更直观，适合浏览、选择和需要视觉反馈的操作；CLI 更直接，适合系统管理、批量处理、远程控制和重复执行的任务。macOS、 Windows 都提供了各自的命令行环境。
