# Houdini MCP
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.184/banner.webp)

[FXHoudini MCP](https://github.com/healkeiser/fxhoudinimcp) 是一个连接 AI 助手与 Houdini 的开源工具。接入后，AI 可以通过 Houdini 自身的 Python 接口创建和连接节点、调整参数、搭建模拟、检查场景并启动渲染。

项目目前提供 215 个工具，覆盖几何处理、材质、动画、USD 场景和 Pyro、RBD、FLIP、Vellum 等特效流程，也支持读取 Houdini 随附的版本对应文档。它让 AI 从提供操作建议，进一步参与实际的场景制作。

采用 MIT 许可证，需要 Houdini 20.5 及以上版本。

# Pigments Play：Arturia 的免费软件合成器
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.184/pigments-play.png)

[Pigments Play](https://www.arturia.com/zh/products/software-instruments/pigments/free) 是 Arturia 基于 Pigments 推出的免费软件合成器，内置 100 个精选预设，涵盖键盘、氛围铺底、贝斯、主音和节奏序列等声音。

[Pigments](https://www.arturia.com/zh/products/software-instruments/pigments/overview) 是 Arturia 备受好评的软件合成器，而 Pigments Play 则将它的声音引擎装进了一个更简单、免费的版本。

![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.184/pigments-play-1.png)

完整版提供 1700 多个预设，以及完整的参数、调制和音序器编辑功能；Play 则精选了 100 个预设，通过亮度、音色、时间和运动四个宏控制来调整声音，更适合想快速找到音色、直接开始创作的人。
