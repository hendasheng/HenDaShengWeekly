# CCMUSIC
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.187/CCMUSIC.jpg)

[CCMUSIC DATASET]([https://ccmusic-database.github.io/overview.html](https://ccmusic-database.github.io/overview.html)) 是一个面向计算音乐学和音乐信息检索（MIR）研究的音乐数据分享平台，包含中国传统乐器音响、流行歌曲 MIDI 与音频，以及带有标注信息的音乐素材。

其中的中国传统乐器音响数据库（CTIS）收录了 287 件民族乐器，包括传统乐器、改良乐器和少数民族乐器。对于想研究中国传统乐器音色，或进行采样、声音分析与音乐交互实验的人来说，是一个很有价值的资源。

部分数据需要提交申请并遵守相应的使用协议，并非全部可以直接下载或自由用于商业项目。

# Project Titan EVO 
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.187/Project%20Titan%20EVO.png)

[Project Titan EVO](https://www.sidefx.com/titan-evo/) 是 SideFX 推出的 Houdini 22 × Unreal Engine 程序化场景制作示范项目，展示了如何利用 Houdini 的程序化能力构建复杂的实时游戏环境。

项目包含建筑、脚手架、管线、桥梁、植被等一系列程序化工具，并结合 Copernicus 材质制作、APEX 角色系统及实时特效等工作流。通过 Houdini Engine 和 HDA，这些工具可以直接在 Unreal Engine 中使用和调整。

官方还提供了完整的 Unreal 工程文件、可运行的演示程序，以及从基础到进阶的系列教程。相比单独学习某个节点或功能，这个项目更适合用来了解 Houdini 如何融入完整的实时制作流程。

# MediaPipe Tasks - Google 提供的机器学习任务 API
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.187/MediaPipe%20Tasks.png)

[MediaPipe Tasks Web Demos](https://google-ai-edge.github.io/mediapipe-samples-web/#/home) 是 Google 提供的一套在线 AI 功能演示，涵盖手势识别、人体姿态追踪、面部关键点检测、图像分割、物体识别，以及音频和文本处理等功能。

可以在网页中体验各项功能，更直观地了解各个模型的效果和性能，对于开发前期的技术选型来说非常方便，可以快速判断哪些功能适合自己的需求。
