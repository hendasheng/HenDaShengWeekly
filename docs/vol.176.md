# OGL - 极简的 WebGL 库
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.176/ogl.png)

> [OGL](https://github.com/oframe/ogl) 是一个小巧而高效的 WebGL 库，面向喜欢最少抽象层且有兴趣创建自己的着色器的开发者。
>
> 该 API 使用 es6 模块编写，没有依赖项，与 ThreeJS 有许多相似之处，但它与 WebGL 紧密耦合，并且功能少得多。
>
> 该库在设计上只进行了必要的最小抽象，因此开发人员仍然可以放心地将其与原生 WebGL 命令结合使用。
>
> 保持较低的抽象级别有助于使库更容易理解、扩展，也使其作为 WebGL 学习资源更具实用性。

# POINTILLISME - 生成式乐器
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.176/POINTILLISME.jpg)

[POINTILLISME](https://www.remodevicocomposer.eu/maxforlive/pointillisme) - 一个基于 Web Audio API 的生成式四声部乐器，将音高、时值、力度、音域、ADSR、声像和装饰音分别进行序列化，并以动态图形谱的形式呈现。生成结果还可以直接导出为音频或四轨 MIDI，继续放进 Ableton Live 等 DAW 里编辑。
