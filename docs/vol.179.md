# 创作更多我最喜欢的 Aphex Twin 曲目
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.179/Generating%20More%20of%20My%20Favorite%20Aphex%20Twin%20Track.webp)

> [创作更多我最喜欢的 Aphex Twin 曲目](https://medium.com/%40alexbainter/generating-more-of-my-favorite-aphex-twin-track-cde9b7ecda3a)
> “aisatsana” 是 Aphex Twin 2012 年专辑《Syro》的最后一首曲目。和 Aphex Twin 大多数更为活跃、复杂的电子音乐不同，aisatsana 非常简单、安静而平和，很适合在需要专注的时候听。
>
> 但这首曲子的长度还不到五分半，显然不足以支撑一次完整的阅读或编程。循环播放也不太理想，因为完全相同的重复很快就会让人觉得单调。
>
> 我开始希望能有一个长达一小时的版本，或者更进一步，有一个系统能够不断生成这首曲子的演奏，让它可以无限持续下去，同时又不会完全重复。
> 
> 因为我的工作就是开发软件，所以我决定试着自己做出这样一个系统。

# JavaScript 系统音乐
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.179/javascript%20system%20music.png)

> [JavaScript 系统音乐](https://teropa.info/blog/2016/07/28/javascript-systems-music)
> 系统音乐是一种探索以下问题的理念：如果我们能够设计系统来为我们生成音乐，而不是自己创作音乐，那会怎样？
>
> 这种想法长期以来一直激励着艺术家和作曲家，并且每当音乐制作中采用新技术时，这种想法就会以新的形式出现。
>
> 20世纪60年代和70年代是极简主义音乐的黄金时期。像史蒂夫·莱奇、特里·莱利、宝琳·奥利维罗斯和布莱恩·伊诺这样的音乐家设计了许多系统，创作出了许多极简主义和氛围音乐的里程碑式作品。他们运用了当时最前沿的技术：磁带录音机、循环乐器和延迟效果器。

# Magenta RealTime 2
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.179/Magenta%20RealTime.gif)
[Magenta RealTime 2](https://magenta.tensorflow.org/) 是 Google Magenta 最近推出的实时音乐模型。和常见的“输入提示词，等它生成一首歌”不同，它更像是一件可以直接演奏的 AI 乐器：按住一个 MIDI 音符或和弦，它就会实时生成跟随和声的完整伴奏，也可以通过文字、音频采样和 MIDI 控制不断改变生成结果。

# VSCO2 Piano — 免费的旧钢琴采样音源
[VSCO2 Piano](https://plugins4free.com/plugin/2729#google_vignette) 是一款免费采样钢琴插件，声音偏暖、偏软，声音不像模拟钢琴音源那么干净，甚至有些杂音，反而显得很真实。我最近在做生成式音乐的实验时经常会用到它。

# ChordKit — 网页端和弦图组件
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.179/chordKit.png)

[ChordKit](https://chordkit.vercel.app/) 是一个用来生成吉他和弦图的 JavaScript 库，可以直接在网页里绘制指板、按弦位置、指法和弦名这些信息。

适合拿来做和弦查询、练琴工具这类项目。和直接使用一张张和弦图片相比，用代码生成会更灵活，样式、尺寸和和弦数据都可以自己控制。

# muted.io — 在线音乐理论工具合集
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.179/muted-io.png)

[muted.io](https://muted.io/) 是一个免费的在线音乐理论工具集合，里面有音阶、调式、和弦、五度圈、钢琴、吉他指板、节奏、音程等大量可交互工具。

# Logopedia — Logo 历史资料库
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.179/logopedia.png)

[Logopedia](https://logos.fandom.com/wiki/Logopedia) 是一个专门收集品牌 Logo 和视觉识别变化的 Wiki。很多品牌从早期版本到现在的 Logo、字标、频道包装、地区版本都能在这里找到，而且通常会按照年份整理。
