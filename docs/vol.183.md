# Houdini Engine for Unreal — 属性参考文档
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.183/houdini2unreal.png)

这份文档整理了 [Houdini Engine for Unreal](https://www.sidefx.com/docs/unreal20.5/_attributes.html) 支持的特殊属性。通过在 Houdini 中设置指定名称的属性，可以控制模型导入 Unreal Engine 后的输出方式，包括网格生成、材质分配、碰撞体、组件属性等。

这份文档早就有了，内容非常丰富，只是对于人类阅读来说不太友好，查找和理解起来都很费劲。当下结合 AI 工具，可以直接根据需求查找对应属性、解释用法，甚至生成 VEX 代码，大幅降低使用门槛，也能进一步释放 HDA 与 UE 联动的潜力。

# Oxide — 免费 Max for Live 磁带退化效果器
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.183/Oxide-m4l.png)
[Oxide](https://www.youtube.com/watch?v=OCeWzK83puQ&list=LL&index=8) 是一款免费的 Max for Live 音频效果器，将磁带退化、弹簧混响、锁相放大器（Lock-In Amplifier）和声音冻结四种功能结合在一起。

比较有趣的是磁带退化功能，开启后声音会随着时间逐渐磨损，直到磁带彻底失效，需要手动更换才能恢复。Lock-In 则可以从声音频谱中提取特定频率，Freeze 能够将某一瞬间的声音冻结成持续变化的声音纹理，而不是简单地循环播放。

很适合处理环境录音、Drone 和长时间演化的氛围音乐。需要 Ableton Live、Max for Live 以及 Max 9 或更新版本。
