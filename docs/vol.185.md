# UE 5.8 引入官方 MCP 支持
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.185/Unreal%20MCP.png)
从 Unreal Engine 5.8 开始，Epic 在引擎中引入 [官方 Unreal MCP 插件](https://dev.epicgames.com/documentation/unreal-engine/unreal-mcp-in-unreal-editor)，让支持 MCP 的 AI 助手直接连接编辑器，执行创建场景对象、调整灯光、创建材质实例等操作。

# MCP 状态下的 Houdini 和 UE
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.185/Rubiks_UE-01.png)

Houdini 和 UE 本来就衔接紧密：Houdini 擅长程序化建模和复杂运算，UE 擅长实时渲染，并能接入丰富的外部信号。两者配合，可以把程序化生成的内容与实时输入结合起来，实现多样的交互体验和视觉效果。

当两边都接入 MCP 后，探索的空间和可实现的范围都被大幅拓宽。想法能够更快落地，更重要的是，验证想法、调整方案、再次尝试的效率也大幅提高。

![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.185/Rubiks_UE-02.png)

![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.185/Rubiks_Houdini-01.png)

![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.185/Rubiks_MaxMsp-01.png)

这是我最近的尝试，以前这种程度的实验是很难进行的，要花费的时间是难以想象，大概率会卡在中间的某一个难点就停止了，这次就顺利很多。

把建模、控制、渲染与声音连接起来，探索多种信号共同驱动的实时演出视觉。

Houdini｜程序化建模

UE｜实时控制与渲染

Max/MSP｜信号汇集与处理

Ableton Live｜声音与音乐


# Zeabur 即将停止运营，伤心
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.185/Zeabur%20%E5%81%9C%E6%AD%A2%E8%BF%90%E8%90%A5%E5%85%AC%E5%91%8A.png)

刚开始用 [Zeabur](https://zeabur.com/zh-CN/blogs/zeabur-is-shutting-down?utm_source=banner&utm_medium=landing&utm_campaign=shutdown-2026) 的时候还没 Vibe Coding 的说法，那时候网站部署、服务器配置这些事情还挺麻烦的。Zeabur 把这些步骤简化了很多，可以大幅减少折腾配置的时间，把更多精力放在想做的东西上。

后来 Vibe Coding 来了，从想法到实际的页面、网站越来越方便，Zeabur 这样的工具也让最后的部署轻松了不少，到现在也还在用，没想到，用着用着就要告别了，伤心难过。
