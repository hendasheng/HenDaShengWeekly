# Symbl-cc - Unicode 符号查询
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.175/symbl-cc.png)

[Symbl.cc](https://symbl.cc/) 是一个 Unicode 符号查询工具，收录了大量特殊字符、数学符号、几何图形、箭头、传统符号等内容。

如果你需要一些不常见的符号来丰富作品界面，Symbl.cc 是一个值得关注的小工具。

# WHATSHIPS - 探索来自 X 的创业公司发布视频
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.175/whatships.png)

[whatships.com](https://whatships.com/) 是一个收集产品发布视频的独立目录，主要整理 X（Twitter）上公开发布的创业项目 Launch Film、产品演示和功能 walkthrough。

很多产品发布视频会随着社交媒体时间线快速消失，whatships 希望建立一个长期可检索的产品发布档案，方便观察不同团队如何展示产品、讲述故事和进行发布。

# GNM - 三维形态生成与编辑
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.175/gnm_logo.png)

[GNM (Generative Neural Morphology)](https://github.com/google/GNM/tree/main?utm_source=chatgpt.com) 是 [Google Research](https://research.google/) 开源的一个用于三维形态生成与编辑的研究项目。

它探索如何利用神经网络学习和生成复杂的三维形状结构，尤其关注生物形态、自然物体等非规则几何对象。项目包含形态生成、三维表示以及相关实验代码，对于程序化建模、生成艺术、数字生物形态等方向都有一定参考价值。

# Seam Carving（内容感知缩放）
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.175/Seam%20Carving.gif)

[内容感知缩放（Seam Carving）](https://www.wikiwand.com/en/Seam_carving) 是一种基于动态规划的图像重构算法，可以在改变图片尺寸时，自动识别并保留重要内容。

# Eulerian Video Magnification - 欧拉视频放大
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.175/Eulerian%20Video%20Magnification.gif)

[欧拉视频放大（Eulerian Video Magnification）](https://hbenbel.github.io/blog/evm/) 是一种用于增强视频中微小变化的图像处理技术。它通过分析视频序列中的像素变化，将肉眼难以察觉的运动、颜色变化等信号进行放大。
