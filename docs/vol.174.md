# CLOMAP / 三维重建和相机求解
![alt text](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.174/COLMAP.webp)

[COLMAP](https://colmap.github.io/index.html) 主要用于从多张照片或视频中恢复相机位置与三维结构。在高斯泼溅模型训练前的数据处理，和实景合成的空间对齐方面都有广泛的应用空间。

这个说起来就这么简单，但实际上还挺复杂的，我做了很多尝试，而且不同工具的支持用法各不相同，同时这方面的工具都在快速发展中。如果你也对此感兴趣，接下来应该会有不少值得关注的变化。
