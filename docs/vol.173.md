# Houdini 22
![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.173/houdini22.png)

![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.173/houdini22-new.png)

这个版本第一眼就是 UI 大更新，以往 UI 更新几乎无感，这一版是明显的变化。

![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.173/houdini22-05-3dgs.png)

我比较关心的是关于高斯泼溅模型的支持，这个版本的 [bakegsplat](https://www.sidefx.com/docs/houdini/nodes/sop/bakegsplat.html)
 节点可以正常加载高斯模型的的独特属性，以获得高斯显示模式，而不是以往的点云形态。

![!\[img\](!\[alt text\]())](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.173/houdini_21-22.png)

前面我一直用第三方插件 [Houdini GSOPs](https://github.com/cgnomads/GSOPs) 解决高斯模型的显示问题，虽然 22 版本原生支持了高斯模型显示（图右），但是效果没有 GSOPs 好（图左），不知道为啥。目前 GSOPs 支持支到 21 版本。

![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.173/houdini-06.png)

新版本还增加了对高斯模型的训练以及像对网格模型那样的骨骼和表面变形处理。

# 中国哲学书电子化计划
![img](https://hendasheng-web.oss-cn-beijing.aliyuncs.com/Weekly/vol.173/%E4%B8%AD%E5%9B%BD%E5%93%B2%E5%AD%A6%E4%B9%A6%E7%94%B5%E5%AD%90%E5%8C%96%E8%AE%A1%E5%88%92.png)

页面 UI 非常带感！

> [中国哲学书电子化计划](https://ctext.org/zhs) 是一个线上开放电子图书馆，为中外学者提供中国历代传世文献，力图超越印刷媒体限制，通过电子科技探索新方式与古代文献进行沟通。收藏的文本已超过三万部著作，并有五十亿字之多，故为历代中文文献资料库最大者。
